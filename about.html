FEATURED PROJECT

My Project

🌤️

WeatherNow

WeatherNow is a weather forecasting website developed using HTML, CSS and JavaScript.

The application provides current weather information, hourly forecasts, 7-day forecasts, weather details and Sun & Moon information.

The main goal of this project is to provide weather information through a clean, responsive and user-friendly interface.

WEATHER NOW

Project Features

🏠

Home

Displays current weather conditions and today's highlights.

📅

Forecast

Shows hourly and 7-day weather forecasts.

📊

Details

Provides humidity, wind, pressure, visibility and other information.

🌙

Sun & Moon

Displays sunrise, sunset and moon information.
